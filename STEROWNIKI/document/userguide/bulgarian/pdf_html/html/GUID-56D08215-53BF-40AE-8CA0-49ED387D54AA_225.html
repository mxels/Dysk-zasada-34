Предлагани услуги

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW
Когато искате компютърът ви да отпечатва чрез сървъра за печат на Brother, трябва да използвате ресурс, познат и като „услуга“. Сървърът за печат на Brother предоставя тези предварително дефинирани услуги:
Услуга (Пример) Дефиниция
BINARY_P1 TCP/IP binary
TEXT_P1 TCP/IP текстова услуга (добавя връщане в началото след всеки нов ред)
PCL_P1 PCL услуга (превключва устройство, съвместимо с PJL, в PCL режим)
BRNxxxxxxxxxxxx *1 TCP/IP binary
*1
Където „xxxxxxxxxxxx“ е MAC адресът (Ethernet адресът) на вашето устройство.
