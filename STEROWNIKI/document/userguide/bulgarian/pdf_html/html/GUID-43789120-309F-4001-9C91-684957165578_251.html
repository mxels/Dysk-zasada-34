MAC адрес

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW

MAC адресът (Ethernet адресът) представлява уникален номер, присвоен към мрежовия интерфейс на устройството. Можете да проверите MAC адреса на вашето устройство от контролния панел.
