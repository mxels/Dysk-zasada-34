Настройване на вашия компютър за получаване на факсове PC-FAX (Windows®)

Свързани модели:MFC‑1900 / MFC‑1900E / MFC‑1900R / MFC‑1901 / MFC‑1905 / MFC‑1905R / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW
  1. Щракнете с десния бутон на мишката върху иконата на (PC-FAX Получаване) в полето за задачи на компютъра, а след това щракнете върху опцията Конфигуриране на PC-Fax Получаване.
    Показва се диалоговият прозорец Конфигуриране на PC-Fax Получаване.
  2. Конфигурирайте тези опции според необходимостта:
    Запис на файла в
    Щракнете върху бутона Преглед, за да промените пътя, използван за записване на файловете от PC-FAX.
    Файлов формат
    Изберете опция .tif или .pdf за формат на получения документ. Форматът по подразбиране е .tif.
    Изпълнение на звуков файл при получаване на факс
    Поставете отметка в това квадратче, за да се изпълнява този WAV файл (звуков файл .wav), когато получавате факс. Ако изберете тази опция, щракнете върху бутона Преглед, за да изберете звуковия файл.
    Добавяне на директория"Startup"
    Изберете това квадратче за отметка за автоматично стартиране на софтуера за получаване на факс PC-FAX при стартиране на Windows®.
    Мрежови настройки
    Щракнете върху бутона Мрежови настройки, за да използвате софтуера за получаване на факс PC-FAX по вашата мрежа.
  3. Щракнете върху OK.
