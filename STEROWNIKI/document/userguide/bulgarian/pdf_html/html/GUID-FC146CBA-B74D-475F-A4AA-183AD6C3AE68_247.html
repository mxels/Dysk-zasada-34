Меню Мрежа на контролния панел на Brother

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW
Менюто Мрежа на контролния панел ви позволява да конфигурирате устройството Brother за вашата мрежа.

Имайте предвид, че устройството Brother включва BRAdmin Light, уеб базирано управление и приложения за дистанционна настройка, които можете да използвате за конфигуриране на различни части на мрежата.

За DCP моделите не се предлага Дистанционна настройка.
Свързани препратки
  • Мрежа
  • TCP/IP
  • Ethernet (само за кабелна мрежа)
  • Статус на кабелна мрежа
  • MAC адрес
  • WLAN помощник (само за безжична мрежа)
  • Съветник за настройка (само за безжична мрежа)
  • WPS/AOSS™ (само за безжична мрежа)
  • WPS с ПИН код (само за безжична мрежа)
  • Статус на WLAN (само за безжична мрежа)
  • Настройка по подразбиране
  • Активиране на кабелна (само за кабелна мрежа)
  • Активиране на WLAN (само за безжична мрежа)
  • Нулиране на мрежовите настройки
  • Намиране на мрежовите настройки, когато се използва контролния панел на Brother
