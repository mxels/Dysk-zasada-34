Какво е Уеб-базирано управление?

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW

Уеб-базираното управление е помощна програма, която използва стандартен уеб браузър за управление на устройството с помощта на HTTP (Hyper Text Transfer Protocol). Въведете IP адреса на устройството в уеб браузъра за достъп и промяна на настройките на сървъра за печат.

  • Препоръчваме Microsoft® Internet Explorer® 8.0/9.0/10.0 за Windows® и Safari 5.0/6.0 за Macintosh. Уверете се, че JavaScript и Cookies са винаги активирани, който и браузър да използвате. Ако използвате друг уеб браузър, уверете се, че е съвместим с HTTP 1.0 и HTTP 1.1.

  • Трябва да използвате TCP/IP протокол в мрежата и да имате валиден IP адрес, програмиран на сървъра за печат и компютъра.
Свързани препратки
  • Научете повече за софтуера и помощните програми за управление на мрежата
  • Научете се да използвате софтуера и помощните програми за управление на мрежата
  • Достъп до уеб базирано управление
  • Намиране на мрежовите настройки, когато се използва Уеб-базирано управление
