Отпечатване в споделена мрежа

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW
В споделена мрежова среда всеки компютър изпраща данни чрез централно управляван компютър. Този тип компютър често се нарича “сървър” или “сървър за печат”. Неговата задача е да управлява всички заявки за печат.
  1. Клиентски компютър
  2. Централно управляван компютър, познат също и като „сървър“ или „сървър за печат“
  3. Ethernet кабел, USB или паралелен (при наличност)
  4. Мрежово устройство (вашето устройство)
  • При по-голяма мрежа препоръчваме печат в среда на споделена мрежа.
  • „Сървърът“ или „сървърът за печат“ трябва да използва TCP/IP протокол.
  • Устройството Brother трябва да има подходящо конфигуриран IP адрес, освен ако не е свързано чрез USB или паралелен интерфейс при сървъра.
