Свързан към компютър с безжична връзка без точка за достъп до безжична LAN мрежа/маршрутизатор в мрежата (Ad-Hoc режим)

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW
Този тип мрежа не разполага с централна точка за достъп до безжична LAN мрежа/маршрутизатор. Всички безжични клиенти комуникират директно един с друг. Когато безжичното устройство Brother (вашето устройство) е част от тази мрежа, то получава всички задачи за печат от компютъра, който изпраща данните за печат.
  1. Безжично мрежово устройство (вашето устройство)
  2. Компютър с безжична връзка

Не можем да гарантираме защитени безжични мрежови връзки с продукти на Windows Server® в режим “Ad-Hoc”.

Свързани препратки
  • Примери за безжична мрежова връзка
  • Конфигуриране на вашето устройство за безжична мрежа в режим “Ad-Hoc” (за IEEE 802.11b/g/n)
