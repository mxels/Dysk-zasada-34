Конфигуриране на IP адреса чрез APIPA

Свързани модели:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW

Сървърът за печат на Brother поддържа протокола за автоматично частно IP адресиране (APIPA). С APIPA DHCP клиентите автоматично конфигурират IP адрес и подмрежовата маска, когато DHCP сървърът не е достъпен. Устройството избира собствен IP адрес в интервала от 169.254.1.0 до 169.254.254.255. Подмрежовата маска автоматично се настройва на 255.255.0.0, а адресът на шлюза – на 0.0.0.0.

APIPA протоколът е активиран по подразбиране. За да деактивирате APIPA протокола, използвайте контролния панел на устройството, приложенията на BRAdmin или уеб-базираното управление.
