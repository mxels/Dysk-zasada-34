Where Can I Find My Brother Machine's Network Settings?

Related Models:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW

Use one of the following methods to find your Brother machine's network settings, for example, IP address, default gateway, and other settings:

  • Print the Network Configuration Report
  • Use your Brother machine's control panel
  • Use BRAdmin Light
  • Use BRAdmin Professional 3
