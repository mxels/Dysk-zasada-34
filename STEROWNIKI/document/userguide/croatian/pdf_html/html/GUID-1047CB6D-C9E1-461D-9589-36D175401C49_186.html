Install BRAdmin Light from the Installer CD-ROM (Windows®)

Related Models:DCP‑1610W / DCP‑1610WE / DCP‑1610WR / DCP‑1612W / DCP‑1612WR / DCP‑1615NW / DCP‑1616NW / MFC‑1910W / MFC‑1910WE / MFC‑1911NW / MFC‑1911W / MFC‑1912WR / MFC‑1915W / MFC‑1916NW
  1. Make sure your Brother machine is on.
  2. Turn on your computer.
    Close any open applications before starting configuration.
  3. Put the Installer CD-ROM into your CD-ROM drive.
  4. If the model name screen appears, select your machine.
  5. If the language screen appears, select your language.
    The CD-ROM main menu will appear.
  6. Click Custom Installation>Network Utilities.
  7. Click the BRAdmin Light button and follow the on-screen instructions to install.

    If the Brother screen does not appear, do the following:

    • (Windows® XP)

      Go to My Computer, double-click the CD-ROM icon, and then double-click start.exe.

    • (Windows Vista® and Windows® 7)

      Go to Computer, double-click the CD-ROM icon, and then double-click start.exe.

    • (Windows® 8)

      Click the (File Explorer) icon on the taskbar, and then go to Computer (This PC). Double-click the CD-ROM icon, and then double-click start.exe.
