Restore Printer Factory Settings

Use this function to return the machine's printer settings to the factory settings.

This will not reset the network settings.

  1. Press Menu.
  2. Press or to display the Printer option, and then press OK.
  3. Press or to display the Reset Printer option, and then press OK.
  4. Follow the machine's instruction to reset printer settings.
  5. Press Stop/Exit.
