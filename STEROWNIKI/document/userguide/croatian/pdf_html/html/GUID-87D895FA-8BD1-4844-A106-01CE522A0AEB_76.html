Scan Using the Scan Button on Your Brother Machine

  • Scan Photos and Graphics
    Send scanned photos or graphics directly to your computer. Brother's ControlCenter software will launch the default graphics application on your computer and open your scanned document automatically.
  • Save Scanned Data to a Folder as a PDF File
    Scan documents and save them to a folder on your computer as PDF files.
  • Scan to E-mail Attachment
    Send a scanned document as an email attachment.
  • Web Services for Scanning on Your Network (Windows Vista® SP2 or greater, Windows® 7 and Windows® 8)
    The Web Services protocol enables Windows Vista® (SP2 or greater), Windows® 7 and Windows® 8 users to scan using a Brother machine on the network. You must install the driver via Web Services.
